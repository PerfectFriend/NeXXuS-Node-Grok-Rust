# Проверка двух нод в одной сети

Это лабораторный пакет Rust-ноды **0.2.0-lab**. Он не закрывает весь план миграции.

Уже можно проверить между Ubuntu и Windows в одной локальной сети:

- HELLO v3 и чат;
- запись файла в сейф `map.bin`;
- одну копию этого файла на вторую ноду;
- ответ на проверку чанка.

В этом пакете нет очереди SMP, описания XFTP, объявления майнера, папки `drive` и веб-панели. Профиль `onion` на Ubuntu запускает системный бинарник `tor`, если он установлен. В обычную проверку двух компьютеров он не входит: для неё нужен профиль `lab`.

Адрес `.onion` программа сама не выдумывает.

## Куда писать лог

Скрипты пишут журнал в каталог, куда вы распаковали архив, и в каталог ноды:

- `install.log` — установка;
- `~/.nexxus-rs/node.log` — старт и команды;
- `~/.nexxus-rs/contact.txt` — строка контакта;
- `lab-test.log` — проверка связи, её и пришлите вместе с `node.log`.

Фразу из двенадцати слов в эти файлы не копируйте. Она печатается один раз при первом запуске. Запишите её отдельно.

## Ubuntu

Распакуйте архив именно в `~/NeXXuS-Grok-Rust`.

```bash
mkdir -p ~/NeXXuS-Grok-Rust
tar -xzf nexxus-ubuntu-x86_64.tar.gz -C ~/NeXXuS-Grok-Rust
cd ~/NeXXuS-Grok-Rust
sudo ./install.sh
```

Если `sudo` недоступен, `install.sh` положит программу в `~/.local/bin` и напишет это в `install.log`.

Откройте порт 4377 на входящие, если на машине включён файрвол:

```bash
sudo ufw allow 4377/tcp
```

Запуск:

```bash
./scripts/start-lab.sh
```

В том же окне появится строка `Контакт: nexxus:1:…`. Она же лежит в `~/.nexxus-rs/contact.txt`. Передайте её на вторую машину. Свой адрес в строке должен быть адресом этой машины в локальной сети, не `127.0.0.1`. Если там `127.0.0.1`, остановите ноду и запустите так:

```bash
nexxus start --data ~/.nexxus-rs --listen 0.0.0.0 --advertise АДРЕС-ЭТОЙ-МАШИНЫ --port 4377
```

## Windows

Распакуйте `nexxus-windows-x86_64.zip` в `C:\NeXXuS-Grok-Rust`. В PowerShell из этой папки:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\install.ps1
.\start-lab.ps1
```

Разрешите `nexxus.exe` входящие подключения по TCP 4377, когда Windows спросит.

Контакт будет в `%USERPROFILE%\.nexxus-rs\contact.txt`.

Если в комплекте нет `nexxus.exe`, а есть только исходники, соберите их в этой папке установленным Rust:

```powershell
cargo build --release -p nexxus
copy target\release\nexxus.exe .
.\install.ps1
```

## Связать две ноды

На каждой машине, когда обе уже запущены, подставьте контакт другой стороны.

Ubuntu:

```bash
./scripts/test-peer.sh 'nexxus:1:ОТПЕЧАТОК:КЛЮЧ@АДРЕС:4377'
```

Windows:

```powershell
.\test-peer.ps1 'nexxus:1:ОТПЕЧАТОК:КЛЮЧ@АДРЕС:4377'
```

Скрипт звонит на вторую ноду, кладёт маленький файл и отправляет строку `hello from ИМЯ-МАШИНЫ`. Текст пробы на английском, чтобы кодовая страница Windows не попортила команду. В ответе `status` поле `peers` не должно быть `-`, а у файла на машине-отправителе со временем должно стать `copies=1`.

Повторите скрипт на второй машине с контактом первой. Так копия пойдёт в обе стороны.

Остановить ноду: Ctrl-C в окне `start`. Каталог `~/.nexxus-rs` не удаляйте между запусками, иначе сменится ключ только если удалить `identity.bin`. Новый каталог — новая фраза.

## Что прислать

С обеих машин, без фразы из двенадцати слов:

- `install.log`;
- `~/.nexxus-rs/node.log` (на Windows `%USERPROFILE%\.nexxus-rs\node.log`);
- `lab-test.log` из каталога распаковки;
- одну строку: совпал ли адрес в контакте с адресом машины в локальной сети.
