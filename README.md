# NeXXuS

[English](README.en.md) · [Español](README.es.md) · **Русский**

![NeXXuS: из серого города в живую сеть](docs/banner.jpg)

NeXXuS — основание другого интернета. Не быстрее старого и не удобнее в первый день. Другого по свойству: без хозяина посередине, без обязательного дата-центра и без чужого диска, который можно выключить одним решением.

Старый интернет остаётся там, где им удобно пользоваться. Сюда уходят те, кому нужно, чтобы копия секрета не жила в одной компании, а старый телефон на зарядке был не мусором, а узлом.

Этот репозиторий — нода на Rust. Эталон протокола пока [NeXXXUs-Grok](https://github.com/PerfectFriend/NeXXXUs-Grok), Linux 0.10.0. Rust его не заменяет, пока не проходит те же испытания. План переноса: [docs/MIGRATION.md](docs/MIGRATION.md).

## Зачем это людям

Обычное облако хранит файл целиком у того, кому вы платите. Он видит метаданные, может отказать в доступе и исчезает вместе с вашим архивом, если так решит.

NeXXuS режет файл на куски по 16 КБ. Каждый кусок шифруется отдельно. Сеть не хранит файл как файл: она хранит немые шифртексты. Собрать их обратно может только тот, у кого есть карта. Карта лежит в журнале владельца, а не на общей витрине.

Узел — это не сервер в стойке. Это старый телефон, домашний компьютер или маленькая машина, которую очистили, оставили в сети и на зарядке. Человек отдаёт диску место. За это сеть оставляет ему личную долю, которую не надо арендовать у чужого хостинга.

## Как устроен узел

1. Двенадцать слов BIP39. Из них выводятся ключи связи, ключ подписи и ключ сейфа. Фраза показывается один раз.
2. На одном ключе может жить несколько устройств. Для журнала это одно хозяйство, не толпа чужих людей.
3. Место под сеть берётся кусками по 16 ГиБ, и только если свободного места хотя бы столько. Меньше — узел хранилищем не становится.
4. Владельцу остаётся одна восьмая отданного места. Это его сейф: секреты и то, что он сам согласился держать. Остальное держит сеть, не он лично.
5. Кусок не лежит тремя копиями на одной полке. Копии разъезжаются по разным узлам. У каждой свой nonce, поэтому шифртексты побайтово разные: одну копию нельзя подставить вместо другой.
6. На узле владельца остаётся его собственная зашифрованная копия. Сеть держит ещё три. Падение чужого диска не стирает файл.
7. Если узел замолчал, 24 часа ничего не снимается. За это время можно включить телефон, сменить сеть или поднять тот же ключ на другой машине. Дольше суток молчания — копии уходят на узлы, которые отвечают. Тридцать дней без срыва поднимают местный рейтинг.
8. Рейтинг и штраф помнит тот, кто сам поймал отказ или подмену. Общего чёрного списка нет: иначе он стал бы новым центром.
9. Подмена чанка видна без вскрытия файла. Идентификатор — это хеш шифртекста. На вопрос «покажи, что кусок ещё тот» можно ответить, только если на диске лежат те самые байты.
10. Внешний диск можно добавить к узлу. Больше отданного места — больше личная доля.
11. Сверх своей доли место берётся не «у облака», а у узлов, которые держат чужие куски. Оплата в этой версии не проверяется и в протокол не вписана.
12. Apple — только клиент. Узла-хранилища на iOS нет: система не отдаёт телефон в вечное фоновое хранение.

## Что уже делает эта нода

Сборка **0.2.0-lab**. С Linux 0.10.0 сходятся:

- двенадцать слов, отпечаток `nxx1`, HELLO v3 и сессионный ключ;
- чат по лабораторному TCP;
- `identity.bin`, закрытый `machine.key`;
- журнал `map.bin` и куски по 16 КБ: Linux открывает журнал Rust, Rust открывает файл Linux;
- одна копия на чужой узел и проверка, что шифртекст на месте;
- льгота и местный штраф;
- профиль `onion`: запускается настоящий бинарник `tor`, адрес берётся только из его `hostname`, звонок идёт через SOCKS5. Своего лукового адреса программа не сочиняет. Нет `tor` — старт с ошибкой;
- очередь `nexxus-smp-v1`: релей хранит шифртекст и отдаёт его только открывшему;
- описание `nexxus-xftp-v1` без адресов узлов;
- `--miner`: свои файлы в бесплатные копии не кладутся;
- папка `drive` — открытая копия сейфа, не тайник.

Лабораторный профиль слушает `0.0.0.0` и публикует адрес машины, чтобы два компьютера в одной сети могли созвониться. Команды управления принимаются только с этой же машины, с `127.0.0.1`.

План этих частей и того, что ещё не сделано: [docs/PLAN.md](docs/PLAN.md).

## Чего в этой сборке нет

Не обещано и не включено:

- оплата и проверка свободных 16 ГиБ;
- живой прогон двух настоящих onion через сеть Tor в обычном тесте;
- веб-панель;
- Android и клиент для Apple.

Пока этого нет, репозиторий — нода для испытания, не магазин приложений и не биржа.

## Две машины

Подробно: [packaging/TEST-LAB.md](packaging/TEST-LAB.md).

Ubuntu, архив с бинарником: [релиз 0.2.0-lab](https://github.com/PerfectFriend/NeXXuS-Node-Grok-Rust/releases/tag/v0.2.0-lab).

```bash
mkdir -p ~/NeXXuS-Grok-Rust
tar -xzf nexxus-ubuntu-x86_64.tar.gz -C ~/NeXXuS-Grok-Rust
cd ~/NeXXuS-Grok-Rust
sudo ./install.sh
./scripts/start-lab.sh
```

На второй машине, когда обе ноды уже слушают порт 4377:

```bash
./scripts/test-peer.sh 'nexxus:1:отпечаток:ключ@адрес:4377'
```

В ответе `peers` не должно быть прочерка. У отправленного файла со временем должно стать `copies=1`. Повторите команду на второй машине с контактом первой.

Windows-архив того же релиза содержит скрипты и исходники. `install.ps1` соберёт `nexxus.exe`, если установлен Rust. Готового exe в архиве нет.

Фраза из двенадцати слов в журналы не пишется. В отчёт её тоже не кладите.

## Сборка из исходников

```bash
cargo test
cargo run -p nexxus -- start --data ~/.nexxus-rs --listen 0.0.0.0 --port 4377
```

Парные испытания с Linux-нодой 0.10.0:

```bash
NEXXUS_JS_DIR=/путь/к/linux-node cargo test --test js_pair --test journal --test replica --test identity
```

Полезные команды, пока нода запущена:

```bash
nexxus ctl --data ~/.nexxus-rs status
nexxus ctl --data ~/.nexxus-rs dial 'nexxus:1:…'
nexxus ctl --data ~/.nexxus-rs put ./файл
nexxus ctl --data ~/.nexxus-rs chat ОТПЕЧАТОК текст
```

Векторы, с которыми сверяется криптография: [vectors/nxx-vectors.json](vectors/nxx-vectors.json). Фраза `legal winner…` из этого файла — публичный тест BIP39, не чей-то сейф.

## Чего нода не делает даже в замысле

Не чинит молчание чужого узла сама и не объявляет человека виновным для всей сети. Не хранит открытые файлы в сейфе: каталог `drive`, когда он появится, останется открытой папкой рядом с шифртекстом. Не ускоряет загрузку. Скорость здесь сознательно не цель. Цель — чтобы файл нельзя было тихо подменить и нельзя было отнять выключением одного сервера.
